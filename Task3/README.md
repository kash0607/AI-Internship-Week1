# AI Automation Workflow

## Objective

To automate customer registration and email confirmation using Google Forms, Google Sheets, Zapier, and Gmail.

---

## Workflow

Google Form → Google Sheets → Zapier → Gmail → Confirmation Email

---

## Workflow Logic

1. User submits registration details through Google Form.
2. Data is automatically stored in Google Sheets.
3. Zapier monitors new spreadsheet rows.
4. When a new row is detected, Zapier triggers Gmail.
5. Gmail sends an automatic confirmation email to the registered user.

---

## Tools Used

* Google Forms
* Google Sheets
* Zapier
* Gmail
